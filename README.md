**Projects**

- [**gulf-tanker-ais**](https://github.com/ethantraister/gulf-tanker-ais): 913 days of ship-tracking data. Tanker calls at loading berths, found from the data alone, track official U.S. crude exports on held-out data (r = 0.53). Simple tanker activity doesn't predict oil prices, and the repo shows those nulls too.
